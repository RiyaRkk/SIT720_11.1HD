# Heart Attack Prediction: Reproduction and Leakage-Aware Improvement

Reproduction of "An efficient stacking-based ensemble technique for early heart attack prediction" (Bhagat et al., Multimedia Tools and Applications, 2025), plus an improved evaluation protocol that removes duplicate-row data leakage.

## Contents
- 11.1HD : full code (Part 1 reproduction and Part 2 solution)
- heart.csv : dataset (Kaggle "Heart Disease Dataset" by johnsmith88, 1025 rows, 14 columns)
- requirements.txt : package versions used
- accuracy_comparison.png, clean_metrics.png : figures generated by the notebook

## Requirements
Python 3.11 or newer (tested with the versions in requirements.txt).

## How to run
1. Create and activate a virtual environment:
   python -m venv venv
   venv\Scripts\activate        (Windows)
   source venv/bin/activate     (Mac/Linux)
2. Install packages:
   pip install -r requirements.txt
3. Make sure heart.csv is in the same folder as the notebook.
4. Open the notebook (VS Code or Jupyter), select the virtual environment as the kernel, and click Run All.

## What the notebook does
- Part 1: trains Logistic Regression, Decision Tree, Random Forest, XGBoost, Naive Bayes, KNN and a Stacking Ensemble on an 80/20 stratified split (random_state=42), and reports Accuracy, Precision, Recall, F1 and AUC.
- Part 2: shows that 723 of the 1025 rows are duplicates, that 75.6% of the test set leaks from the training set, then deduplicates the data (302 unique rows), re-splits, and re-evaluates all models.

## Expected key outputs
- Duplicate rows: 723 (302 unique)
- Leaked test rows in the original split: 155 of 205 (75.6%)
- Leaked rows after deduplication: 0
- Stacking Ensemble accuracy on the clean split: 0.7541

## Notes
- Results are reproducible because random_state=42 is fixed everywhere.
- The paper does not state its train/test split ratio, so an 80/20 split was assumed.
